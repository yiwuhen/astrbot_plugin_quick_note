# 随手记 (astrbot_plugin_quick_note)

AstrBot 插件 —— **随口说一句，机器人自动记住并整理**。需要时按优先级排出清单，或按时间排成周视图。

## 为什么值得装

- **零摩擦录入**：`记 明天下午3点交报告`，时间自动识别，不用选日期选时间
- **AI 直接调用**：接了大模型后连 `记` 都不用打——直接说「别忘了周五交周报」，AI 自己调工具记
- **WebUI 数据面板**：插件详情页里打开可视化面板，浏览/编辑所有会话的记录、按周查看、直接改配置
- **图片卡片**：「清单 图」「本周 图」把清单/周安排渲染成精致的图片发出来；跟 AI 说「发张图看看」也行
- **自动整理**：过期置顶 → 紧急 → 有时间 → 随手记，一眼看清先干啥
- **周视图**：`清单 本周` 按周一到周日排开，今天高亮，像日历一样
- **多群独立**：每个群/私聊一本清单

## 快速开始

```
[你]     记 明天下午3点交报告
[机器人] ✅ 记下了
        📝 交报告
        ⏰ 截止：11-11 15:00
        编号 #1 · 「清单 完成 1」打勾

[你]     记 周五买牛奶 不急
[机器人] ✅ 记下了
        📝 周五买牛奶 → 识别为「买牛奶」🌿 不急

[你]     清单
[机器人] 📝 清单 · 2 条未完成
        📅 有时间
          #1 交报告（11-11 15:00）
        📥 随手记
          #2 买牛奶（11-13） 🌿

[你]     清单 本周
[机器人] 📅 本周安排（11-09 ~ 11-15）
        周一 11-09
        周二 11-10 ← 今天
          · 15:00 交报告（#1）
        ...
```

## 时间怎么写都行

| 写法 | 识别结果 |
| --- | --- |
| `记 明天交报告` | 明天（默认按 09:00 排序） |
| `记 明天下午3点交报告` | 明天 15:00 |
| `记 周三晚8点开会` | 本周三 20:00 |
| `记 下周五交周报` | 下周五 |
| `记 11月15号体检` | 11-15（今年的过了自动顺延一年） |
| `记 15号还信用卡` | 本月 15 号（过了则下月） |
| `记 3天后回访` | 3 天后 |
| `记 今晚8点约饭` | 今天 20:00 |
| `记 10:30 组会` | 今天 10:30（今天已过则明天） |
| `记 今天晚上下班后买水果` | 今天 20:00（「晚上/下午/早上」等时段词自动给默认时刻） |
| `记 今天下班后取快递` | 今天 18:00（「下班后/放学后/晚饭后」也认） |
| `记 晚上去健身` | 今天 20:00（已过则明天） |

## 优先级

| 写法 | 效果 |
| --- | --- |
| `记 明天答辩 紧急` 或 `记 明天答辩 !!` | 🔥 紧急组置顶 |
| `记 买装饰品 不急` | 🌿 不急，排在最后 |
| 不写 | 普通，按时间排 |

## 命令一览

```
记 <内容>               记一条（别名：记一下 / 随手记一条）
清单                    按优先级排列（别名：随记 / 备忘 / 待办 / todo）
清单 本周               本周周视图（清单 下周 看下周）
清单 完成 3             给 #3 打勾（别名：做完）
清单 删 3               删除 #3
清单 已完成             最近完成/删除的记录
本周                    周视图（别名：周视图 / week）
随手记帮助              完整帮助
```

## AI 直接调用（Function Calling，默认开）

| 工具名 | 触发说法 | 参数 |
| --- | --- | --- |
| `quicknote_add` | 「记住…」「别忘了…」「提醒我…」 | 内容（可带时间）、优先级（可选） |
| `quicknote_list` | 「我最近都有啥事」「记了什么」 | 无 |
| `quicknote_week` | 「这周有什么安排」「下周要干嘛」 | 周偏移（0 本周 / 1 下周） |
| `quicknote_complete` | 「那条完成了」 | 编号 |
| `quicknote_delete` | 「把那条删了」 | 编号 |

- 需要模型支持函数调用（AstrBot 提供商配置里默认开启）
- 时间解析在插件侧完成，模型只需保留用户原话，不存在模型算错日期的问题
- 不想让 AI 动清单，把配置项 `llm_tools` 关掉

## 自动捕捉（默认开）

群里说下面这类话会自动收进清单，不必发命令：

```
记住周三下午交作业
别忘了买牛奶
帮我记一下 3天后回访客户
```

刻意只认这几个开头词，普通闲聊不会被误记；不想要可关掉 `auto_capture`。

## 图片卡片

不想看文字版？说一句就出图：

```
[你]     清单 图          ← 清单做成图片卡片
[你]     本周 图          ← 周视图做成图片日历（「本周 下周图」看下周）
[你对AI] 发张图看看        ← AI 调工具时把 as_image 设为 true
```

图片是本地渲染的高清 PNG：过期标红并显示「已过 N 小时/天」，紧急红点、不急绿点。

**周视图默认是课表样式**：7 列（周一~周日）× 4 行时段（全天 / 上午 / 下午 / 晚上）网格，
每条随记按时刻落进对应格子，卡片左边色条表示优先级、过期红条，今天整列高亮；
没写时刻的归「全天」行，底部收纳已过期 / 更远 / 不限时间的条目。
喜欢原来的按天列表？把配置 `image_week_timetable` 关掉即可。

> 💡 只写日期的条目（如「今天交作业」）不会因为默认排序时刻过了就显示「已过 N 小时」，
> 时刻过了才算真过期。

**自动降级，绝不白屏**：环境缺 Pillow 或中文字体、渲染出错、发送失败、清单为空，
都会自动回退成纯文本清单——图片只是锦上添花，不影响任何功能。
配套配置：`image_output`（开关）、`image_max_items`（每组最多几条）、`image_font`（手动指定字体）。
图片是临时文件，落在 `data/plugin_data/astrbot_plugin_quick_note/images/`（每次出图一个新文件、
文件名带时间戳，不会互相覆盖）。清理策略三重兜底：
1. 插件加载/重载时扫一遍目录
2. 出图后顺手清理，6 小时最多扫一次（节流，长期运行也不会堆积）
3. 超过 24 小时直接删；同时最多保留最新 200 张，被刷屏时按数量兜底

渲染中途崩溃会删掉写了一半的图片，不会留下损坏文件。

## WebUI 数据面板

在 AstrBot WebUI 的「插件」页点开本插件卡片，进入详情页即可打开**数据面板**：

- **概览统计**：所有会话的 未完成 / 已过期 / 今天到期 / 本周 / 已完成，多会话一键切换
- **清单管理**：按 已过期 → 紧急 → 有时间 → 随手记 分组浏览，支持搜索；点圈打勾、✏️ 编辑（内容/时间/优先级）、🗑 删除；面板新增条目同样支持「明天下午3点」这类中文时间
- **周视图**：周一到周日逐天排列，今天高亮，可前后翻周；已过期 / 更远 / 不限时间的条目单独收纳在底部
- **配置**：直接开关「自动捕捉」「AI 直接调用」，调整清单每组显示条数（3~50），保存即写回插件配置文件

面板与聊天里的清单实时同步（同一份 `notes.json`），在面板里删掉一条，群里再发「清单」就能看到效果。

> 面板依赖较新版本的 AstrBot（支持插件可视化视图）。老版本会自动跳过面板注册，聊天命令与 AI 工具不受影响。

## 数据存储

```
data/plugin_data/astrbot_plugin_quick_note/notes.json
```

按会话隔离，不受插件重装/更新影响。

## 常见问题

**Q：同一天很多条，周视图会乱吗？**
每天按时刻排序，没写时刻的排在当天最前；「不限时间」的统一放在周视图底部，不占具体某天。

**Q：「记住我们上次说的那个」会误记吗？**
不会——解析不出实质内容（去掉引导词后为空）时插件不动作。

**Q：过期了怎么办？**
清单里自动进入「⚠️ 已过期」分组并标注过期多久，处理完打勾或删除即可；周视图里过期项单独列在顶部，不占用本周的格子。
